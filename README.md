# Electric Vehicle (EV) Population Dashboard

This project is a frontend dashboard that visualizes key insights from the Electric Vehicle (EV) Population dataset.

## Live Dashboard
Explore the live dashboard here: [EV Dashboard]( Network URL: http://192.168.9.32:8501)

## Features
- Interactive visualizations of EV data
- Insights on EV distribution by Model Year, Make, and State
- User-friendly and intuitive interface
