# MapUp - Analytics Dashboard Assessment

## Overview

The objective of this assessment is to analyze the provided Electric Vehicle (EV) population data and create a frontend dashboard that visualizes key insights about the dataset. This repository contains the necessary data and instructions for demonstrating your analytical and dashboard creation skills. You are free to use any tech stack to create the dashboard.

## Dataset

The Electric Vehicle Population dataset is available in the [Electric Vehicle Population Data (CSV)](./data-to-visualize/Electric_Vehicle_Population_Data.csv). For more information about the dataset, you can visit the [Kaggle dataset page](https://www.kaggle.com/datasets/willianoliveiragibin/electric-vehicle-population).

> **Note:** The dataset has been reduced in size to keep the frontend bundle lightweight.

## Tasks

### Dashboard Creation

- Develop a frontend dashboard that presents key insights from the dataset.
- Design the dashboard for effective communication of important metrics and visualizations.
- Include visualizations such as charts, graphs, and tables to highlight trends and relationships in the data.
- Ensure the dashboard is user-friendly and intuitive.

### Deployment

- Deploy the dashboard to a hosting platform of your choice.
- Ensure the dashboard is publicly accessible.

## Live Dashboard

The deployed dashboard is available here: [EV Dashboard](https://ev-dash-board.web.app/)

## Evaluation Criteria

Your submission will be evaluated based on the following:

- **Analytical Depth:** The depth of analysis and insights derived from the dataset.
- **Dashboard Design:** The clarity, aesthetics, and usability of the dashboard.
- **Insightfulness:** The effectiveness in conveying key insights about electric vehicles.
