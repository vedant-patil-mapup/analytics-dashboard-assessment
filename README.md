# 🚗 MapUp - Analytics Dashboard for Electric Vehicle Insights ⚡

Welcome to **MapUp**, an interactive analytics dashboard designed to showcase insights into the Electric Vehicle (EV) population. This project combines data analysis, visualization, and modern web development to deliver a user-friendly experience that highlights trends and metrics in EV adoption.

---

## 🌟 Overview

The goal of this project was to analyze the EV population dataset and create a dashboard that presents meaningful insights. This repository includes:

1. **Frontend Dashboard**: Built with React and Vite to provide an intuitive interface.
2. **Data Analysis Notebook**: A Jupyter Notebook for exploratory data analysis (EDA), visualization, and error handling.
3. **Exported PDF Report**: A compiled showcase of key graphs and insights generated from the notebook.

The app is live and accessible at: [🔗 Deployed Dashboard on Netlify](https://deepeshniranjanevdashboard.netlify.app/)  


---

## 📊 Dataset

The **Electric Vehicle Population Data** forms the backbone of this project. It provides detailed information about EV adoption trends. For more about the dataset, visit the [Kaggle Dataset](https://www.kaggle.com/).

⚠️ *Note*: The dataset has been reduced for optimal frontend performance.

---

## 🛠️ Features

### 🚀 Dashboard Highlights:
- **Dynamic Charts and Graphs**: Visualize EV adoption trends and metrics using `chart.js` and `react-chartjs-2`.
- **Interactive Maps**: Explore location-based EV data with `react-leaflet` and heatmap layers.
- **CSV Downloads**: Export filtered data directly from the dashboard using `react-csv`.
- **Error-Free Experience**: Integrated data validation and error handling for seamless visualization.

### 📈 Data Analysis:
- **EDA and Visualization**: Conducted using Python in Jupyter Notebook.
- **Error Handling**: Ensures the dataset is clean and ready for analysis.
- **Exported Report**: Key insights compiled into a PDF.
